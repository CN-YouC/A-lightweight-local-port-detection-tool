==================================================
基于PortTools修改的,一个免安装的小工具[“空闲端口 + 占用端口 + 占用文件完整路径”的轻量项目]，双击就能看到本机：
      1) 哪些端口被占用了、占用它的是哪个文件、在哪个文件夹；
      2) 指定范围里哪些端口是空闲的、可以直接拿来用。
--------------------------------------------------------------------
使用：
    1. 双击 端口检测工具.exe（不需要安装任何东西）。
    2. 打开后自动检测一次。
    3. 上半部分 = 被占用的端口（TCP 监听 + UDP 绑定）。
    4. 下半部分 = 空闲端口：先在顶部填范围（默认 8000 - 8100），
       再点“查找空闲端口”。

    端口            端口号
    协议            TCP / UDP
    本地地址        0.0.0.0 表示所有网卡；127.0.0.1 表示只本机
    状态            LISTENING = 正在监听；UDP 没有状态
    PID             进程编号
    进程名          占用它的进程
    占用文件        占用它的文件的完整路径
    所在文件夹      这个文件所在的目录

    PS：如端口是被 python.exe / node.exe / cmd.exe 这类“解释器”占用的，光看“占用文件”只能看到解释器本身；这时看“命令行”或把鼠标悬停在行上，就能看到真正跑的是哪个脚本（例如 D:\bot\bot.py）。
--------------------------------------------------------------------
权限说明:
    普通用户能读到自己的进程；系统进程（svchost 等）可能显示“（读取不到，需管理员权限）”。
    点右上角“以管理员身份重启”，会弹 UAC，确认后就能看到全部进程的文件路径。
--------------------------------------------------------------------
常用操作:
    复制整行 / 复制占用文件路径 / 打开文件所在文件夹 / 结束该进程
    双击某一行 = 打开该文件的所在文件夹并选中它。
--------------------------------------------------------------------
其他电脑:
    把 端口检测工具.exe 这一个文件拷到那台电脑上双击就行，
    不用装 Python、不用装 .NET，Win10 / Win11 自带运行环境。
--------------------------------------------------------------------
导出:
    “导出 CSV”把当前表格导出成 CSV，可以用 Excel 打开（带 BOM，不乱码）。
--------------------------------------------------------------------
编译:
    源码：端口检测工具.cs
    双击 编译.bat 即可重新生成 exe（用 Windows 自带的 csc.exe 编译，不需要装 Visual Studio）
--------------------------------------------------------------------
卸载:
    直接删除整个文件夹即可，不写注册表、不留后台服务。
